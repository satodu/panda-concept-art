# SHIZUKA.

静か, "quiet". An aged-paper and sumi-ink interface (wabi-sabi): off-white paper with fibre, real ink blooms, half-erased numbers, **one** primary (a single faded red kanji) and lots of emptiness. Peace and discomfort together.

> **Start here:** [`SHIZUKA.md`](SHIZUKA.md) is the master reference (one file, the whole system, with a master prompt for AI). [`PROMPTS.md`](PROMPTS.md) has the 144 prompts (image, icons, banners, people, image editing, video, video editing, audio, text, code).

The primary (shu `#A8473A`, indigo, moss) is **the kanji**. Sumi black `#1C1B19` and paper white `#F3EFE3` are its own.

## Commands (at the repository root)

```bash
npm run studio                                   # Remotion Studio
npm run fonts                                    # downloads the TTFs used in the PNGs
node tools/make-asset.mjs --concept shizuka --type banner --title "MY PROJECT" --png
node tools/make-asset.mjs --concept shizuka --type banner --primary "#2F3F6B" --png   # swaps the primary
npx remotion render src/index.ts Shizuka-Intro out/shizuka.mp4 --props='{"primary":"#2F3F6B"}'
```
