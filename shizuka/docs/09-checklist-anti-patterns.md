# 09. Checklist and anti-patterns

**Checklist**
- [ ] paper with fibre and burnt edges
- [ ] one ink bloom
- [ ] one primary (the kanji), one per screen
- [ ] numbers with faded last digits
- [ ] radius 40/24/999, contact shadow only
- [ ] basics stay basic (straight lines, no ornament on UI)
- [ ] slow motion
- [ ] half the screen empty

**Anti-patterns**
- Concentric rings (they look like a target), chrome, glossy sphere, lime, glow (REV.02).
- Flat white paper, "too clean".
- Bright red or big blocks of the primary (that is Oriental).
- Seal, stamp, hanko or fake kanji.
- Wobbly lines, big shadows, neumorphism, "dark tech" theme.
- AI-generated text inside the image.
