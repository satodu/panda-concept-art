# GALDR.

Primitive Nordic cyberpunk, minimal: carved Elder Futhark runes, thin circuit lines, near-black, bone paper, **one** ice accent and physical crystal shards lit like runestones.

> **Start here:** [`GALDR.md`](GALDR.md) is the master reference (one file, the whole system, with a master prompt for AI). [`PROMPTS.md`](PROMPTS.md) has the 144 prompts (image, icons, banners, people, image editing, video, video editing, audio, text, code).

The primary (ice, jade, amber) defines the identity. Black `#0C0C0B`, white `#F3F0E6` and bone `#E9E4D6` are its own.

| File/folder | Content |
|---|---|
| `GALDR.md` | **master reference** (22 sections) |
| `PROMPTS.md` | prompt library, generated by `tools/build-prompts.mjs` |
| `docs/01…14` | guides by topic (concept, tokens, UI, icons, banners, backgrounds, prompts, motion, checklist, primary color, slides, social, web, Figma) |
| `tokens/` | `tokens.json` (single source), `tokens.css`, `components.css` (ready-made components) |
| `examples/showcase.html` | example page with live primary swap |
| `reference/` | source images and MDs |
| `../src/galdr/` | 7 Remotion compositions (Galdr-Intro, -Ui, -Components, -Kit, -Logo, -Mobile, -Social) |

## Commands (at the repository root)

```bash
npm run studio                                   # Remotion Studio
npm run fonts                                    # downloads the TTFs used in the PNGs
node tools/make-asset.mjs --concept galdr --type banner --title "MY PROJECT" --png
node tools/make-asset.mjs --concept galdr --type banner --primary "#FFB86B" --png   # swaps the primary
npx remotion render src/index.ts Galdr-Intro out/galdr.mp4 --props='{"primary":"#FFB86B"}'
```
