# 09. Checklist and anti-patterns

## Before delivering

- [ ] Canvas `#0C0C0B`; bone paper only on reading panels.
- [ ] One accent (ice). No red or gold.
- [ ] Violet/cyan only inside the crystal.
- [ ] Chamfered corners (never rounded on panels).
- [ ] Depth by light and layers; no hard shadow.
- [ ] Display title with an ice full stop.
- [ ] 4+ typographic levels on screen.
- [ ] All visible text is real content (no design labels).
- [ ] Numbered figure caption wherever there is an image.
- [ ] Contrast: `boneInk` on `bone` and `primary` on `ink` > 7:1; `textMuted` on `ink2` ≥ 4.5:1.
- [ ] Waifu/seer in a sober frame.

## Anti-patterns

| Avoid | Because |
|---|---|
| Red, gold, hard shadow | it is the language of Oriental Brutalismo |
| Acid green, distorted chrome, neon glow | turns "gamer/cyber" and breaks the seriousness |
| Glassmorphism with rounded blobs | it is what made the old mobile screen feel odd |
| Crystal flat in one color | loses the physical feel; always facet + light |
| Illegible decorative text | redo it in HTML/Figma |
| More than one live color | the ice loses force |

## Common AI-image errors

- Prompt leaking as text (`BONE-PAPER PANELS`, hex codes). Fix with the rule in `07-ai-prompts.md`.
- Swapped letters in tables ("Crynerytal"). Use the images only as reference.
- Repeated numbering in callouts (A, A). Fix in the HTML version.
